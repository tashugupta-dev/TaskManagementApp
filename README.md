# Task Management App

A simple ASP.NET Core MVC application to manage daily tasks.

## 🚀 Features

- Add new tasks
- Edit existing tasks
- Delete tasks with confirmation
- Search tasks by Status
- Display task status with badges (Completed / Pending)

## 🛠️ Technologies Used

- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Bootstrap 5
- Razor Views

## 📂 Project Structure

- Models → TaskItem Model
- Controllers → TaskController
- Views → Razor Views (Index, Create)
- Data → AppDbContext

## 📊 Database

Uses Code First approach with Entity Framework Core.
